## 1. 概要

本システムは、組合員が自身の出資配当情報や組合員情報をオンラインで参照・更新できるWebシステムである。
組合員コードとパスワードによる認証を行い、ログイン後に出資配当金のお知らせ確認・配当金受取方法の変更・マイページでの組合員情報管理を提供する。

## 2. システム構成

| 項目 | 内容 |
|:---|:---|
| フロントエンド | TypeScript / React |
| バックエンド | Python |
| データベース | NoSQL |
| 認証方式 | 組合員コード＋パスワード認証 |

## 3. 業務フロー

1. 組合員が組合員コードとパスワードを入力してログインする
2. トップ画面にて出資配当金お知らせ一覧とマイページへのリンクを確認する
3. 出資配当金お知らせを選択し、出資残高・配当金額等の詳細情報を確認する
4. 必要に応じて配当金の受取方法を変更する
5. マイページにて登録済みの組合員情報（住所等）を確認・更新する
6. 操作完了後、ログアウトする

## 4. 機能要件

### 4.1 ログイン機能（LGN_001）

- 組合員コードおよびパスワードを入力してログインできること
- 認証失敗時は適切なエラーメッセージを表示すること
- 認証成功後はトップ画面へ遷移すること

### 4.2 ログアウト機能（LGN_002）

- システムから安全にログアウトできること
- ログアウト後はログイン画面へ遷移すること
- セッション情報を適切に破棄すること

### 4.3 トップ画面表示機能（TOP_001）

- ログイン後にトップ画面を表示できること
- 出資配当金お知らせ一覧を表示できること
- マイページへのリンクを表示できること

### 4.4 出資配当金お知らせ確認機能（DIV_001）

- 出資残高を表示できること
- 配当金額を表示できること
- その他出資配当情報の詳細を表示できること

### 4.5 配当金受取方法変更機能（DIV_002）

- 当年の配当金受取方法を選択できること
- 変更内容を保存できること
- 変更後に確認メッセージを表示できること

### 4.6 マイページ（組合員情報表示・更新）機能（MYP_001）

- 登録済みの組合員情報（住所等）を表示できること
- 組合員情報を更新できること

## 5. 画面構成

- ログイン画面
- トップ画面（出資配当金お知らせ一覧,マイページリンク）
- 出資配当金お知らせ画面
- マイページ（組合員情報表示・更新）画面

## 6. 画面遷移

```
ログイン画面 → トップ画面
トップ画面 → 出資配当金お知らせ画面 → 更新 → トップ画面
トップ画面 → マイページ画面 → 更新 → マイページ画面
各画面 → ログアウト → ログイン画面
```

## 7. データ要件

- 組合員情報（組合員コード、氏名、住所等）
- 認証情報（パスワード）
- 出資情報（出資残高、出資配当金額等）
- 配当金受取方法情報
- お知らせ情報

## 8. 非機能要件

- 画面は一定時間内に表示されること
- 認証・認可を実施すること
- セッション管理を適切に行うこと
- 個人情報・金融情報の通信は暗号化すること
- ログを出力すること

## 9. 前提・制約

- 組合員のみが利用対象である
- ログイン後のみ各機能にアクセスできること

## 10. 想定テスト観点

- 正しい組合員コード・パスワードでログインできること
- 誤った認証情報でログインできないこと
- ログアウト後に認証が必要なページへアクセスできないこと
- 出資配当金情報が正しく表示されること
- 配当金受取方法の変更が正しく保存・反映されること
- 組合員情報の更新が正しく保存・反映されること
