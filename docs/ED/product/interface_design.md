## 2. 共通仕様

### 2.1 共通リクエストヘッダー

| ヘッダー名 | 必須 | 型 | 説明 |
|-----------|------|----|------|
| Content-Type | ○ | string | application/json 固定 |
| Accept | ○ | string | application/json 固定 |
| Authorization | △ | string | Bearer {JWT} 形式（認証必須エンドポイントのみ） |
| X-Request-Id | ○ | string | UUID v4。リクエスト追跡用 |
| X-Api-Version | - | string | APIバージョン。省略時は最新バージョンを使用 |

### 2.2 共通レスポンスヘッダー

| ヘッダー名 | 説明 |
|-----------|------|
| X-Request-Id | リクエスト時と同じ値をエコーバック |
| X-Response-Time | サーバー処理時間（ms） |

### 2.3 共通エラーレスポンス

```json
{
  "success": false,
  "data": null,
  "errors": [
    {
      "code": "E_101",
      "message": "ユーザIDは必須です"
    }
  ]
}
```

- エラーコードはerror-rule.mdに準拠
- メッセージは日本語でユーザー向けに記載

### 2.4 HTTPステータスコード規約

| ステータスコード | 用途 |
|----------------|------|
| 200 OK | 取得・更新成功 |
| 201 Created | 登録成功 |
| 204 No Content | 削除成功 |
| 400 Bad Request | バリデーションエラー |
| 401 Unauthorized | 認証エラー |
| 403 Forbidden | 認可エラー |
| 404 Not Found | リソース未存在 |
| 409 Conflict | 重複エラー |
| 422 Unprocessable Entity | ビジネルールエラー |
| 500 Internal Server Error | サーバー内部エラー |

### 2.5 データ型定義

| 論理型 | 物理型(JSON) | 備考 |
|--------|-------------|------|
| 文字列 | string | UTF-8 |
| 整数 | number | 64bit整数相当 |
| 小数 | number | 金額はstringで渡す |
| 真偽値 | boolean | true / false |
| 日付 | string | ISO 8601 YYYY-MM-DD |
| 日時 | string | ISO 8601 UTC |
| 配列 | array |  |
| オブジェクト | object |  |
| null | null | 明示的にnullを返す場合のみ |

## 3. インタフェース定義

### IF-LOGIN: ログイン

| 項目 | 内容 |
|------|------|
| インタフェースID | IF-LOGIN |
| インタフェース名 | ログイン |
| 概要 | 組合員コード・パスワードによる認証を行い、JWTを発行する |
| HTTPメソッド | POST |
| エンドポイント | /api/v1/login |
| 認証 | なし |
| 冪等性 | なし |
| タイムアウト | 10秒 |
| レート制限 | 5回/分/ユーザー |
| セキュリティ | パスワードはハッシュ化、JWTは署名付き。PIIはレスポンスに含めない |

#### リクエストパラメータ

| # | フィールド名 | 型 | 必須 | 桁数/範囲 | 制約 | 例 |
|---|------------|----|------|----------|------|----|
| 1 | member_code | string | ○ | 7桁 | 半角数字 | "1234567" |
| 2 | password | string | ○ | 8-72桁 | 英大文字・小文字・数字・記号を各1文字以上含む | "P@ssw0rd!" |

#### レスポンスパラメータ

| # | フィールド名 | 型 | NULL | 説明 |
|---|------------|-----|------|------|
| 1 | token | string | 不可 | JWTトークン |
| 2 | expires_in | number | 不可 | 有効期限（秒） |

#### エラー一覧

| HTTPステータス | エラーコード | 発生条件 |
|----------------|------------|---------|
| 400 | E_101 | 必須項目未入力、形式不正 |
| 401 | E_001 | 認証失敗 |
| 500 | E_900 | サーバー内部エラー |

---

### IF-LOGOUT: ログアウト

| 項目 | 内容 |
|------|------|
| インタフェースID | IF-LOGOUT |
| インタフェース名 | ログアウト |
| 概要 | セッション破棄・JWT無効化を行う |
| HTTPメソッド | POST |
| エンドポイント | /api/v1/logout |
| 認証 | JWT |
| 冪等性 | あり |
| タイムアウト | 5秒 |
| レート制限 | 10回/分/ユーザー |
| セキュリティ | JWTブラックリスト化 |

#### リクエストパラメータ

なし（JWTはヘッダーで送信）

#### レスポンスパラメータ

| # | フィールド名 | 型 | NULL | 説明 |
|---|------------|-----|------|------|
| 1 | success | boolean | 不可 | ログアウト成功フラグ |

#### エラー一覧

| HTTPステータス | エラーコード | 発生条件 |
|----------------|------------|---------|
| 401 | E_001 | JWT不正・期限切れ |
| 500 | E_900 | サーバー内部エラー |

## 4. 外部システム連携

### 4.1 認証基盤（例: 外部IdP）
- 方式: JWT発行・検証（OpenID Connect想定）
- 連携項目: member_code, password, JWT
- タイムアウト: 5秒
- エラー時: 401/500を返却

### 4.2 メール送信サービス
- 方式: REST API
- 連携項目: email, subject, body
- タイムアウト: 10秒
- エラー時: 500を返却
