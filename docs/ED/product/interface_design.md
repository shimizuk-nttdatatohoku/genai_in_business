## 2. 共通仕様

### 2.1 認証・認可

- 認証方式は組合員コードとパスワードによる認証とし、ログイン成功時にサーバーがセッションを開始する。
- セッション管理は Cookie ベースとし、`Set-Cookie` で `HttpOnly`、`Secure`、`SameSite=Lax` を付与する。
- ログイン後の API は、ログイン済み本人のセッションのみアクセス可能とする。
- 他人のデータ参照・更新要求は `403 Forbidden` とし、エラーコード `E_002` を返却する。

### 2.2 共通リクエストヘッダー

| ヘッダー名 | 必須 | 型 | 説明 |
|-----------|------|----|------|
| `Content-Type` | ○ | string | `application/json` 固定。GET は送信不要 |
| `Accept` | ○ | string | `application/json` 固定 |
| `X-Request-Id` | ○ | string | UUID 形式。トレーシング用 |
| `X-CSRF-Token` | △ | string | `POST`、`PUT`、`DELETE` で必須。サーバー払い出し値 |

### 2.3 共通レスポンスヘッダー

| ヘッダー名 | 説明 |
|-----------|------|
| `X-Request-Id` | リクエストと同一値を返却 |
| `Cache-Control` | 個人情報を含むため `no-store, no-cache, must-revalidate` |
| `Set-Cookie` | ログイン成功時にセッション Cookie を設定 |

### 2.4 共通レスポンス形式

**成功時**

```json
{
  "success": true,
  "data": {},
  "errors": []
}
```

**失敗時**

```json
{
  "success": false,
  "data": null,
  "errors": [
    {
      "code": "E_101",
      "message": "組合員コードは必須です"
    }
  ]
}
```

### 2.5 共通エラーコード

| エラーコード | HTTP | 用途 | メッセージ例 | リトライ |
|-------------|------|------|--------------|----------|
| `E_001` | 401 | 認証失敗 | 組合員コードまたはパスワードが正しくありません | 不可 |
| `E_002` | 403 | 認可エラー | 対象データへアクセスできません | 不可 |
| `E_101` | 400 | 必須エラー | 郵便番号は必須です | 不可 |
| `E_102` | 400 | 形式エラー | 電話番号の形式が正しくありません | 不可 |
| `E_201` | 400 | 業務エラー | 受付期間外のため変更できません | 不可 |
| `E_202` | 400 | 業務エラー | 受取済のため変更できません | 不可 |
| `E_404` | 404 | 未存在 | お知らせが見つかりません | 不可 |
| `E_901` | 500 | システムエラー | 時間をおいて再度お試しください | 可 |

### 2.6 HTTP ステータスコード規約

| ステータスコード | 用途 |
|----------------|------|
| 200 OK | 取得・更新・ログアウト成功 |
| 201 Created | ログイン成功時のセッション開始 |
| 400 Bad Request | 入力エラー、業務エラー |
| 401 Unauthorized | 認証エラー、セッション無効 |
| 403 Forbidden | 認可エラー |
| 404 Not Found | 対象未存在 |
| 500 Internal Server Error | サーバー内部エラー |

### 2.7 データ型定義

| 論理型 | 物理型（JSON） | 形式 / 備考 |
|--------|----------------|-------------|
| 文字列 | `string` | UTF-8 |
| 整数 | `integer` | 32 bit 整数 |
| 金額 | `string` | 数値文字列。小数点以下 2 桁まで |
| 真偽値 | `boolean` | `true` / `false` |
| 日付 | `string` | `YYYY-MM-DD` |
| 日時 | `string` | ISO 8601 `YYYY-MM-DDTHH:mm:ssZ` |
| 配列 | `array` | 0 件以上 |
| オブジェクト | `object` | キーは camelCase |

### 2.8 非機能・セキュリティ

- 通信は TLS1.2 以上を前提とする。
- 個人情報および口座関連情報を含むレスポンスはブラウザキャッシュ禁止とする。
- `X-Request-Id` をアプリケーションログへ出力し、`endpoint`、`method`、`user_id` と紐づけて追跡可能とする。
- パスワード、口座番号、生メールアドレスはログ出力しない。
- タイムアウトは参照系 10 秒、更新系 15 秒を上限目安とする。
- 更新 API は二重送信時に同一内容であれば最終状態整合を優先する。
- CORS は同一オリジンのみ許可する。

## 3. インタフェース定義

### IF-001: ログイン

| 項目 | 内容 |
|------|------|
| インタフェースID | IF-001 |
| インタフェース名 | ログイン |
| 概要 | 組合員コードとパスワードを受け取り、認証成功時にセッションを開始する |
| HTTP メソッド | POST |
| エンドポイント | `/api/v1/auth-sessions` |
| 認証 | 不要 |
| 冪等性 | なし |

#### リクエストパラメーター

**Body（application/json）**

| # | フィールド名 | 論理名 | 型 | 必須 | 桁数 / 範囲 | 制約 | 例 |
|---|--------------|--------|----|------|-------------|------|----|
| 1 | `userCode` | 組合員コード | string | ○ | 6..10 桁 | 半角数字のみ | `"123456"` |
| 2 | `password` | パスワード | string | ○ | 8..32 文字 | 前後空白除去なし、マスク対象 | `"Passw0rd!"` |

**リクエスト例**

```json
{
  "userCode": "123456",
  "password": "Passw0rd!"
}
```

#### レスポンスパラメーター

**成功時 - 201 Created**

| # | フィールド名 | 論理名 | 型 | NULL | 説明 |
|---|--------------|--------|----|------|------|
| 1 | `sessionId` | セッションID | string | 不可 | 監査用識別子 |
| 2 | `userCode` | 組合員コード | string | 不可 | ログイン済み本人のコード |
| 3 | `loginName` | ログイン名 | string | 不可 | ヘッダ表示用 |
| 4 | `csrfToken` | CSRF トークン | string | 不可 | 状態変更 API 呼出用 |
| 5 | `lastLoginAt` | 前回ログイン日時 | string | 可 | ISO 8601 |

**レスポンス例（成功）**

```json
{
  "success": true,
  "data": {
    "sessionId": "6f9619ff-8b86-d011-b42d-00cf4fc964ff",
    "userCode": "123456",
    "loginName": "新開 太郎",
    "csrfToken": "csrf-4f5d6c7b8a",
    "lastLoginAt": "2026-05-20T18:22:15Z"
  },
  "errors": []
}
```

**エラーレスポンス一覧**

| HTTPステータス | エラーコード | 発生条件 |
|--------------|-------------|----------|
| 400 | `E_101` | 必須項目未入力 |
| 400 | `E_102` | 組合員コード桁数不正 |
| 401 | `E_001` | 認証失敗 |
| 500 | `E_901` | サーバー内部エラー |

#### 処理フロー

1. リクエストバリデーション
2. 認証情報照合
3. セッション作成
4. CSRF トークン払い出し
5. セッション Cookie 設定
6. 201 レスポンス返却

#### 備考・制約事項

- 認証失敗時はパスワードを保持しない。
- パスワード誤り回数によるアカウントロック要件は現時点では未定義とする。

### IF-002: ログアウト

| 項目 | 内容 |
|------|------|
| インタフェースID | IF-002 |
| インタフェース名 | ログアウト |
| 概要 | 現在のログインセッションを破棄する |
| HTTP メソッド | DELETE |
| エンドポイント | `/api/v1/auth-sessions/current` |
| 認証 | セッション必須 |
| 冪等性 | あり |

#### リクエストパラメーター

- Body なし
- セッション Cookie 必須
- `X-CSRF-Token` 必須

#### レスポンスパラメーター

**成功時 - 200 OK**

| # | フィールド名 | 論理名 | 型 | NULL | 説明 |
|---|--------------|--------|----|------|------|
| 1 | `loggedOutAt` | ログアウト日時 | string | 不可 | ISO 8601 |

**レスポンス例（成功）**

```json
{
  "success": true,
  "data": {
    "loggedOutAt": "2026-05-21T09:10:00Z"
  },
  "errors": []
}
```

**エラーレスポンス一覧**

| HTTPステータス | エラーコード | 発生条件 |
|--------------|-------------|----------|
| 401 | `E_001` | セッション無効 |
| 500 | `E_901` | サーバー内部エラー |

#### 備考・制約事項

- セッションが既に無効な場合も 401 を返却する。
- 成功時はセッション Cookie を失効させる。

### IF-003: 出資配当金お知らせ一覧取得

| 項目 | 内容 |
|------|------|
| インタフェースID | IF-003 |
| インタフェース名 | 出資配当金お知らせ一覧取得 |
| 概要 | ログイン済み本人に紐づく出資配当金お知らせ一覧を取得する |
| HTTP メソッド | GET |
| エンドポイント | `/api/v1/dividend-notices` |
| 認証 | セッション必須 |
| 冪等性 | あり |

#### リクエストパラメーター

**Query**

| # | パラメーター名 | 論理名 | 型 | 必須 | デフォルト | 制約 | 例 |
|---|----------------|--------|----|------|-----------|------|----|
| 1 | `page` | ページ番号 | integer | - | 1 | 1 以上 | `1` |
| 2 | `pageSize` | 取得件数 | integer | - | 20 | 1..100 | `20` |

#### レスポンスパラメーター

**成功時 - 200 OK**

| # | フィールド名 | 論理名 | 型 | NULL | 説明 |
|---|--------------|--------|----|------|------|
| 1 | `userCode` | 組合員コード | string | 不可 | ヘッダ表示用 |
| 2 | `loginName` | ログイン名 | string | 不可 | ヘッダ表示用 |
| 3 | `items` | お知らせ一覧 | array | 不可 | 一覧データ |
| 4 | `items[].noticeId` | お知らせID | string | 不可 | UUID 形式 |
| 5 | `items[].fiscalYear` | 対象年度 | integer | 不可 | 西暦 |
| 6 | `items[].title` | お知らせタイトル | string | 不可 | 1..100 文字 |
| 7 | `items[].isNew` | 新着フラグ | boolean | 不可 | 未確認時 true |
| 8 | `items[].publishedAt` | 公開日時 | string | 不可 | ISO 8601 |
| 9 | `pagination` | ページング情報 | object | 不可 | `page`、`pageSize`、`totalCount` を返却 |

**レスポンス例（成功）**

```json
{
  "success": true,
  "data": {
    "userCode": "123456",
    "loginName": "新開 太郎",
    "items": [
      {
        "noticeId": "ntc-2026-0001",
        "fiscalYear": 2026,
        "title": "2026年度分 出資配当金・出資金残高等のお知らせ",
        "isNew": true,
        "publishedAt": "2026-04-01T00:00:00Z"
      },
      {
        "noticeId": "ntc-2025-0001",
        "fiscalYear": 2025,
        "title": "2025年度分 出資配当金・出資金残高等のお知らせ",
        "isNew": false,
        "publishedAt": "2025-04-01T00:00:00Z"
      }
    ],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "totalCount": 2
    }
  },
  "errors": []
}
```

**エラーレスポンス一覧**

| HTTPステータス | エラーコード | 発生条件 |
|--------------|-------------|----------|
| 401 | `E_001` | セッション無効 |
| 500 | `E_901` | サーバー内部エラー |

#### 備考・制約事項

- 表示順は `fiscalYear` 降順、同一年度内は `publishedAt` 降順とする。
- 0 件時も 200 を返却し、`items` は空配列とする。
