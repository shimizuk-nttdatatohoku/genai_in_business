# 処理設計書

**ファイルパス**: `docs/ED/product/DIV_001_process-design.md`

## 1. 機能概要

| 項目 | 内容 |
|---|---|
| 機能ID | DIV_001 |
| 機能名 | 出資配当金お知らせ確認 |
| 目的/ゴール | 選択した年度のお知らせに対する出資残高、配当金額、受取状況、受取方法候補を確認できるようにする。 |
| 利用者 | 組合員 |
| 画面/操作トリガー | トップ画面のお知らせリンククリック、出資配当金お知らせ画面の初期表示 |
| 入力 | notice_id、session_id |
| 出力 | お知らせタイトル、対象年度、受取状況、受取方法、出資残高、配当情報詳細 |
| 前提条件 | ログイン済みであること。選択したお知らせが当該組合員に公開されていること。 |

## 2. 入出力データ定義

### 2.1 入力項目

| 項目名 | 型 | 必須 | 制約 | 初期値 |
|---|---|---|---|---|
| session_id | string | Y | 有効セッションであること | セッション保持値 |
| notice_id | string | Y | トップ画面で選択したお知らせID | URLパラメータ |
| fiscal_year | number | N | お知らせに含まれる年度。notice_id から導出可 | なし |

### 2.2 出力項目

| 項目名 | 型 | 内容 |
|---|---|---|
| notice_title | string | 例: 2026年度分 出資配当金・出資金残高等のお知らせ |
| header_user_code | string | ヘッダ表示用の組合員コード |
| header_login_name | string | ヘッダ表示用の利用者名 |
| receipt_status | enum | 未受取 / 受取済 |
| receipt_method | enum | 出資振替 / 登録口座振込 / 現金受取 |
| capital_balance_amount | number | 出資金残高 |
| dividend_amount | number | 配当金額 |
| dividend_rate_before_tax | number | 税引前配当率 |
| dividend_rate_after_tax | number | 税引後配当率 |
| explanatory_message | string | 受取期限や注意事項 |
| support_link | string | 詳細説明へのリンク |

### 2.3 画面状態

| 状態名 | 内容 |
|---|---|
| loading | 初期表示/API取得中 |
| success | 詳細表示完了 |
| error | 取得失敗 |

## 3. 処理フロー（正常系）

1. 利用者がトップ画面のお知らせリンクをクリックする。
2. フロントエンドは `notice_id` を引き継いで出資配当金お知らせ画面へ遷移する。
3. 画面初期表示時に詳細取得APIを呼び出す。
4. APIはセッションを検証し、対象 `notice_id` が利用者に公開されているか確認する。
5. お知らせ情報、当年の配当情報、配当金受取方法情報を取得する。
6. 取得した情報をもとに、受取状況、現在の受取方法、注意書き、詳細テーブルを組み立てる。
7. フロントエンドは画面上部にお知らせ名、ヘッダに組合員コードとログイン名、中段に受取状況・受取方法・説明文、下段に出資配当情報を表示する。
8. 利用者が戻るボタンをクリックした場合はトップ画面へ戻る。

### 3.1 分岐条件

| 条件 | 結果 |
|---|---|
| 対象お知らせが存在する | 詳細表示 |
| 対象お知らせが存在しない | エラー表示してトップ画面へ戻す |
| 受取状況が受取済 | 受取方法変更UIを参照専用表示にする |

### 3.2 画面遷移

| 遷移元 | 条件 | 遷移先 |
|---|---|---|
| トップ画面 | お知らせリンククリック | 出資配当金お知らせ画面 |
| 出資配当金お知らせ画面 | 戻るクリック | トップ画面 |
| 出資配当金お知らせ画面 | ログアウトクリック | ログイン画面 |

### 3.3 トランザクション境界

| 開始 | 終了 | 内容 |
|---|---|---|
| 詳細取得API開始時 | レスポンス返却時 | 参照専用処理のため更新トランザクションなし |

## 4. 入力チェック

| 項目 | チェック内容 | エラーコード | 画面表示 |
|---|---|---|---|
| notice_id | 未指定 | E_101 | 「表示対象が指定されていません」 |
| notice_id | 利用者に紐づかない | E_201 | 「対象のお知らせを表示できません」 |
| session_id | 有効性確認 | E_003 | ログイン画面へ遷移 |

## 5. 例外/エラー処理

### 5.1 入力エラー

| 検知条件 | エラーコード | 表示内容 | 復帰方法 |
|---|---|---|---|
| notice_id 未指定 | E_101 | 「表示対象が指定されていません」 | トップ画面へ戻る |

### 5.2 業務エラー

| 検知条件 | エラーコード | 表示内容 | 処理 |
|---|---|---|---|
| 対象お知らせ不存在 | E_201 | 「対象のお知らせを表示できません」 | トップ画面へ戻す |
| 非公開のお知らせ参照 | E_202 | 「対象のお知らせを表示できません」 | トップ画面へ戻す |
| 利用者情報と配当情報の紐付不整合 | E_203 | 「配当情報を確認できませんでした」 | エラー画面またはトップ画面へ遷移 |

### 5.3 システムエラー

| 検知条件 | エラーコード | リトライ | 表示内容 | ログ |
|---|---|---|---|---|
| DB取得タイムアウト | E_901 | 再試行可 | 「情報の取得に失敗しました」 | request_id、endpoint、method、user_id、stacktrace |
| 未処理例外 | E_999 | 再試行可 | 「システムエラーが発生しました」 | 同上 |

### 5.4 セッション切れ/権限不足

| 事象 | エラーコード | 処理 |
|---|---|---|
| セッション切れ | E_003 | ログイン画面へ遷移 |
| 権限不足 | E_004 | 403相当画面またはログイン画面へ遷移 |

## 6. データ更新・整合性

| 区分 | 内容 |
|---|---|
| 参照データ | お知らせ情報、配当情報、配当金受取方法情報、組合員基本情報 |
| 更新データ | なし |
| 更新順序 | 1. セッション確認 2. お知らせ公開確認 3. 配当情報取得 4. 受取方法取得 |
| 整合性ルール | notice_id と配当情報、受取方法情報は同一年度かつ同一組合員に紐づくこと |
| 排他 | 参照専用のため排他制御なし |
| 冪等性 | 同一 `notice_id` の再表示は同一結果を返す |

## 7. ログ/監査/運用観点

| 区分 | 記録内容 |
|---|---|
| 操作ログ | request_id、機能ID、組合員コード、notice_id、結果、実行日時 |
| 監査ログ | 金融情報参照として、対象年度、閲覧結果を記録 |
| 障害解析 | request_id、endpoint、method、stacktrace、user_id |
| 性能観点 | 初期表示は3秒以内を目標。金融明細取得は1件単位で行い、一覧読込は行わない |

## 8. 前提

- 画面イメージの「現金受取用バーコード発行」導線は別機能とし、本機能では表示可否のみ判定対象とする。
- 受取方法の更新処理自体は DIV_002 で扱うため、本機能は参照主体とする。
