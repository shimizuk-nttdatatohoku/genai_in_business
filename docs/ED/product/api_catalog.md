## 2. API詳細（APIごと）

### 2.1 API-001：ログイン
- IF-ID：IF-001
- 目的：組合員コードとパスワードを受け取り、認証成功時にセッションを開始する
- method/path：POST /api/v1/auth-sessions
- 認証/認可：認証不要
- 想定呼出元（画面/バッチ等。資料にある範囲で）：ログイン画面
- 関連機能ID：LGN_001

#### リクエスト
- path：なし
- query：なし
- body（主要項目のみ箇条書きで）：
  - userCode: string, required, 6..10 桁, 半角数字のみ
  - password: string, required, 8..32 文字
- バリデーション/業務ルール（記載があれば）：
  - userCode と password は必須
  - userCode は桁数および数字形式を満たすこと
  - password はマスク対象とし、前後空白除去なし
- 共通ヘッダー：Accept 必須、X-Request-Id 必須、Content-Type は application/json

#### レスポンス
- 正常時（主要項目）：
  - 201 Created
  - sessionId
  - userCode
  - loginName
  - csrfToken
  - lastLoginAt
- ページング（該当時）：なし
- 備考：Set-Cookie で HttpOnly、Secure、SameSite=Lax を付与したセッション Cookie を返却

#### エラー（必須）
- HTTPステータス別の条件：
  - 400: 必須項目未入力、組合員コード桁数不正
  - 401: 認証失敗
  - 500: サーバー内部エラー
- 業務エラー（コード/代表メッセージ/ユーザー表示可否）：
  - E_101: 組合員コードは必須です, 表示可, リトライ不可
  - E_102: 組合員コードの形式が正しくありません, 表示可, リトライ不可
  - E_001: 組合員コードまたはパスワードが正しくありません, 表示可, リトライ不可
  - E_901: 時間をおいて再度お試しください, 表示可, リトライ可
- システムエラー（タイムアウト/依存サービス障害等）：500 で E_901 を返却
- リトライ可否：E_901 のみ可

#### 非機能（記載があれば）
- タイムアウト：更新系扱いとして 15 秒を上限目安
- レート制限：要確認
- ログ/監査（相関ID等）：X-Request-Id を request_id としてログ出力、password はログ出力禁止

- method/path：GET /api/v1/dividend-notices
- 認証/認可：セッション必須、本人のみ
- 想定呼出元（画面/バッチ等。資料にある範囲で）：トップ画面表示
- 関連機能ID：TOP_001

#### リクエスト
- path：なし
- query：
  - page: integer, optional, default 1, min 1
  - pageSize: integer, optional, default 20, range 1..100
- body（主要項目のみ箇条書きで）：なし
- バリデーション/業務ルール（記載があれば）：
  - page は 1 以上
  - pageSize は 1..100
  - 表示順は fiscalYear 降順、同一年度内は publishedAt 降順
- 共通ヘッダー：Accept 必須、X-Request-Id 必須

#### レスポンス

  - 200 OK
  - userCode
  - loginName
  - items[].noticeId
  - items[].fiscalYear

  - items[].isNew
  - items[].publishedAt
  - pagination.page
  - pagination.pageSize
  - pagination.totalCount
- ページング（該当時）：page/pageSize/totalCount を返却
- 備考：0 件時も 200 を返却し、items は空配列

#### エラー（必須）
- HTTPステータス別の条件：
  - 401: セッション無効
  - 500: サーバー内部エラー
- 業務エラー（コード/代表メッセージ/ユーザー表示可否）：

### 2.5 API-005：配当金受取方法更新
- IF-ID：IF-005
- 目的：指定されたお知らせに対する当年分の配当金受取方法を更新する
- method/path：PUT /api/v1/dividend-notices/{noticeId}/receipt-method
- 認証/認可：セッション必須、本人のみ
- 想定呼出元（画面/バッチ等。資料にある範囲で）：配当金受取方法変更画面の更新操作
- 関連機能ID：DIV_002

#### リクエスト
- path：
  - noticeId: string, required, 1..50 文字
- query：なし
- body（主要項目のみ箇条書きで）：
  - receiptMethod: string, required, 選択肢内のみ
- バリデーション/業務ルール（記載があれば）：
  - noticeId 必須
  - receiptMethod 必須
  - receiptMethod は BANK_TRANSFER または COUNTER_PICKUP
  - 受付期間外は更新不可
  - receiptStatus が RECEIVED の場合は更新不可
  - 同一 noticeId と同一 receiptMethod の再送は同一結果
- 共通ヘッダー：Accept 必須、Content-Type 必須、X-Request-Id 必須、X-CSRF-Token 必須

#### レスポンス
- 正常時（主要項目）：
  - 200 OK
  - noticeId
  - receiptStatus
  - receiptMethod
  - updatedAt
  - message
- ページング（該当時）：なし
- 備考：詳細再取得なしでも画面更新できるだけの情報を返却

#### エラー（必須）
- HTTPステータス別の条件：
  - 400: 必須エラー、形式エラー、受付期間外、受取済のため変更不可
  - 401: セッション無効
  - 403: 本人以外のデータ更新
  - 404: 対象お知らせ未存在
  - 500: サーバー内部エラー
- 業務エラー（コード/代表メッセージ/ユーザー表示可否）：
  - E_101: 配当金受取方法は必須です, 表示可, リトライ不可
  - E_102: 配当金受取方法の形式が正しくありません, 表示可, リトライ不可
  - E_201: 受付期間外のため変更できません, 表示可, リトライ不可
  - E_202: 受取済のため変更できません, 表示可, リトライ不可
  - E_001: 組合員コードまたはパスワードが正しくありません, 表示可, リトライ不可
  - E_002: 対象データへアクセスできません, 表示可, リトライ不可
  - E_404: お知らせが見つかりません, 表示可, リトライ不可
  - E_901: 時間をおいて再度お試しください, 表示可, リトライ可
- システムエラー（タイムアウト/依存サービス障害等）：500 で E_901 を返却

## 5. 前提・要確認事項
- 前提：認証方式は組合員コードとパスワードによるセッション認証とし、ログイン成功時に Cookie ベースのセッションを開始する
