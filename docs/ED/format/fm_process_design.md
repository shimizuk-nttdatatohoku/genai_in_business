# ユーザ認証
## 処理概要

- 画面入力されたユーザID、パスワードでユーザ認証を実施する。

## URL
- /userAuthorization


## 画面遷移
- 遷移元
  - ログイン画面

- 遷移先：
  - 認証成功時：〇〇画面
  - 認証失敗時：ログイン画面


## 処理内容
### 入力
-  ユーザID
-  パスワード

### 出力
- 認証成功時
  - なし
- 認証失敗時
  - エラーコード

### 処理詳細

1. 入力値のユーザIDとパスワードで[Mapper_ユーザテーブル.select](../aaa.md)を呼び出し、認証結果に設定する。

2. 認証結果が1の場合、〇〇画面に遷移する。

3. 認証結果が1以外の場合、エラーコード「E_001」を設定し、ログイン画面に遷移する。
