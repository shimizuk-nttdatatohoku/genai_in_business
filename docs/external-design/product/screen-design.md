## 2. 画面詳細

### 2.1 【SCR-001】ログイン画面
#### 2.1.1 概要
- 目的: 組合員を認証し、認証済みセッションを開始する。
- 利用者（ロール）: 組合員
- 画面種別: 認証
- 前提条件: 未ログイン状態であること。
- 入力: 組合員コード、パスワード
- 出力: 認証結果、エラーメッセージ、認証済みセッション
- 関連機能: LGN_001

#### 2.1.2 画面構成
- エリア構成: ヘッダロゴ、認証フォーム、エラーメッセージエリア、ログインボタン
- 初期表示時の状態: 組合員コードとパスワードは空、初期フォーカスは組合員コード、エラー表示なし
- 非同期/ローディング表示方針: ログイン実行中はボタンを非活性化し、フォーム全体に送信中状態を表示する

| F-LGN-001 | システムロゴ | 表示 | 画像 | string | N | - | 表示用固定値 | 常時 | 不可 | 画面識別用 |
| F-LGN-002 | 組合員コード | 入力 | テキスト | string | Y | 半角数字 6..10 桁 | 空 | 常時 | 可 | ログインID |
| F-LGN-003 | パスワード | 入力 | パスワード | string | Y | 8..32 文字 | 空 | 常時 | 可 | マスク表示 |
| F-LGN-004 | エラーメッセージ | 表示 | アラート | string | N | - | 非表示 | 認証失敗時または入力エラー時 | 不可 | エラーコードは画面表示しない |

#### 2.1.7 バリデーション／エラー設計
- 入力チェック一覧: 組合員コードは必須・半角数字 6..10 桁、パスワードは必須・8..32 文字
- エラー分類: 入力エラーは項目下に表示、認証エラーはフォーム上部に表示、システムエラーはフォーム上部に表示
- セッションタイムアウト時の扱い: 本画面では該当なし
- 画面状態: loading は送信中表示、error はメッセージ表示、success は SCR-002 へ遷移

#### 2.1.8 権限制御
- ロール別の表示/編集可否: 未ログイン利用者のみ表示
- ボタン活性/非活性条件: 必須未入力時または送信中は非活性

#### 2.1.9 画面遷移
- 遷移元: なし、SCR-002、SCR-003、SCR-004
- 遷移先: SCR-002
- 遷移条件: 認証成功
- ブラウザ戻る/リロード時の期待動作: 未ログイン時は本画面を再表示、ログイン済みで本画面へ到達した場合は SCR-002 へリダイレクト

#### 2.1.10 前提・要確認事項
- 前提: TLS により通信を暗号化する
- 要確認: 組合員コードの正式桁数、パスワードポリシー詳細

### 2.2 【SCR-002】トップ画面

- 目的: ログイン済み組合員へ最新のお知らせ一覧とマイページ入口を提供する。
- 利用者（ロール）: 組合員
- 画面種別: ダッシュボード
- 前提条件: ログイン済みセッションが有効であること。
- 入力: 一覧からの選択、マイページ遷移、ログアウト操作
- 出力: お知らせ一覧、ログイン中組合員情報、遷移結果
- 関連機能: TOP_001, LGN_002

#### 2.2.2 画面構成
- エリア構成: ヘッダ、ログイン情報表示、ログアウトボタン、お知らせ一覧エリア、マイページエリア
- 初期表示時の状態: 画面表示時にお知らせ一覧とログイン中ユーザ情報を自動取得する
- 非同期/ローディング表示方針: 初回表示時は一覧エリアにスケルトンを表示し、取得後に一覧へ置換する

#### 2.2.6 一覧/検索の設計
- 検索条件: なし
- 検索実行タイミング: 初期表示時に自動取得
- 一覧: お知らせ年度、タイトル、未確認ラベルを表示する。年度降順、同年度内は更新日時降順とする。
- ページング: 1 画面 20 件、20 件超過時はページング表示
- 0件時表示: 空状態メッセージを表示する

- 入力チェック一覧: 該当なし

#### 2.2.8 権限制御
- ロール別の表示/編集可否: 組合員のみ表示
- ボタン活性/非活性条件: データ取得中は遷移リンクを一時非活性

#### 2.2.9 画面遷移
- 遷移元: SCR-001、SCR-003、SCR-004
- 遷移先: SCR-003、SCR-004、SCR-001
- 遷移条件: お知らせ選択、マイページ選択、ログアウト
- ブラウザ戻る/リロード時の期待動作: セッション有効時は再取得して再描画、無効時は SCR-001 へ遷移

- 前提: お知らせ一覧には当該組合員に公開中のデータのみ表示する
- 要確認: New ラベル判定条件、一覧の最大件数、既読管理有無
