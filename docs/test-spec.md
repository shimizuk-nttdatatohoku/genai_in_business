# テスト仕様

## 概要

本ドキュメントは、プロジェクトのテスト方針とテストケースを定義します。

## テスト方針

### テストレベル
1. **ユニットテスト**: 各関数・コンポーネントの単体テスト
2. **統合テスト**: API エンドポイントの統合テスト
3. **E2E テスト**: ユーザーシナリオに基づく End-to-End テスト

### カバレッジ目標
- ユニットテスト: 80% 以上
- 統合テスト: 主要 API エンドポイント 100%

## フロントエンドテスト

### ツール
- テストフレームワーク: Jest / React Testing Library
- E2E: Playwright または Cypress

### テストケース例
| No | テスト名 | 内容 | 期待結果 |
|----|---------|------|---------|
| F-001 | ユーザー一覧表示 | ユーザー一覧画面を開く | ユーザーが一覧表示される |
| F-002 | ユーザー登録 | 登録フォームに入力して送信 | 新しいユーザーが追加される |

## バックエンドテスト

### ツール
- テストフレームワーク: pytest
- モック: unittest.mock

### テストケース例
| No | テスト名 | エンドポイント | 期待結果 |
|----|---------|------------|---------|
| B-001 | ユーザー一覧取得 | GET /users | 200 OK + ユーザー一覧 |
| B-002 | ユーザー作成 | POST /users | 201 Created + 作成ユーザー |
| B-003 | ユーザー取得 | GET /users/{id} | 200 OK + ユーザー情報 |
| B-004 | 存在しないユーザー取得 | GET /users/{id} | 404 Not Found |
