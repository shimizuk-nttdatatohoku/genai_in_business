# 処理設計ルール

# 基本方針

- 業務ロジックを明示する
- 処理順を明示する
- 条件分岐を明示する
- 呼出Repositoryを明示する
- エラー時動作を明示する
- AIエージェントが実装可能な粒度で記載する

---

# 処理単位

- 1処理1責務とする
- 巨大処理を避ける

---

# 処理記載ルール

以下を記載する

- 入力
- 出力
- 処理順
- 条件分岐
- DBアクセス
- エラー処理

---

# DBアクセス

- Repository単位で記載する
- 使用Collectionを明示する

---

# 条件分岐

- IF条件を明示する
- 正常系/異常系を分離する

---

# エラー制御

- ErrorCodeを記載する
- エラー条件を記載する

---

# トランザクション

- 必要な場合のみ明示する
- 更新順を明示する

---

# 設計時注意事項

- 処理を省略しない
- 「適切に処理する」等の曖昧表現禁止
- DB更新条件を明示する
- 外部API呼出を明示する

---

# 禁止事項

- UI処理混在
- SQL直接記載
- 実装コード記載
- 曖昧表現
- 巨大処理設計
