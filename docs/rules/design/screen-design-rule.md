# 画面設計ルール

# 基本方針

- 画面単位で責務を明確化する
- UI動作を明示する
- 曖昧表現を使用しない
- API連携を明示する
- エラー時動作を明示する
- 画面遷移を明示する

---

# 画面ID

- `SCR-XXX` 形式を使用する

---

# 設計時注意事項

- UI動作を省略しない
- API呼出を明示する
- 入力チェックを記載する
- エラー時動作を記載する
- 画面遷移を記載する

---

# エラー表示

- ユーザ向けメッセージを表示する
- エラーコードを画面表示しない

---

# 状態管理

以下状態を考慮する

- loading
- error
- success

---

# 禁止事項

- 曖昧表現
- API未記載
- エラー時動作未記載
- 入力チェック未記載
- 画面遷移未記載
