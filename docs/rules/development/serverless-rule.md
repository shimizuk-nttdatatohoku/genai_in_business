# Serverless実装ルール

# 基本方針

- AWS Lambda前提で実装する
- ステートレス設計とする
- 短時間実行を前提とする
- AIエージェントが解釈しやすい単純構成を優先する

---

# Lambda制約

- ローカルファイル保存禁止
- 永続メモリ前提禁止
- セッション保持禁止
- グローバル状態保持禁止

---

# 一時ファイル

- `/tmp` のみ使用可能

---

# 実装方針

- 短時間で完了する処理とする
- 長時間バッチを避ける
- 外部接続を最小化する

---

# 環境変数

- Lambda環境変数を使用する
- Secret直書き禁止

---

# API Gateway

- API Gateway経由を前提とする
- CORSを考慮する

---

# ログ

- CloudWatch出力を前提とする
- loggerを使用する

---

# 禁止事項

- セッション保持
- ローカルキャッシュ依存
- ファイル永続保存
- 常駐前提処理
- スレッド常駐
- EC2前提コード
- localhost固定
