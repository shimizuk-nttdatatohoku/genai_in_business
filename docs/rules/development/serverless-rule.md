# Serverless実装ルール

# 基本方針

- AWS Lambda前提で実装する
- ステートレス設計とする
- Lambda のタイムアウト内で確実に完了する短時間処理を前提とする
- AIエージェントが解釈しやすい単純構成を優先する

---

# Lambda制約

- ローカルファイル保存禁止
- 永続メモリ前提禁止
- セッション保持禁止
- グローバル状態保持禁止

---

# 一時ファイル

- `/tmp` のみ使用可能

---

# 実装方針

- 1 リクエストで短時間に完了する処理だけを実装する
- Lambda を常駐バッチのように長時間占有する処理を避ける
- 外部 API や DB への接続回数を必要最小限にする

---

# 環境変数

- Lambda環境変数を使用する
- Secret直書き禁止
- `docs/rules/common/implementation-rule.md` を参照する

---

# API Gateway

- API Gateway経由を前提とする
- CORSを考慮する

---

# ログ

- CloudWatch出力を前提とする
- loggerを使用する

---

# 禁止事項

- セッション保持
- ローカルキャッシュ依存
- ファイル永続保存
- Lambda コンテナの常駐を前提にした処理
- スレッド常駐
- EC2前提コード
