# 共通実装ルール

# 基本方針

- 環境依存値は設定値または環境変数から取得する
- 実行環境に依存する固定値を実装へ埋め込まない

---

# 環境依存値

- `http://localhost:3000` や `https://api.example.com` のような URL をソースコードへ直書きしない
- 開発環境だけを前提に `localhost` を固定値として実装しない

---

# 設計時注意事項

- backend は `os.getenv` 等で設定値を取得する
- frontend は `VITE_` プレフィックスの環境変数や共通設定を利用する
- test は実行環境ごとの差分を設定またはモックで吸収する

---

# 禁止事項

- URLハードコード
- localhost固定
