# テストプロンプト

## 概要

このプロンプトは、GitHub Copilot や他の生成AIを使用してテストコードを生成するためのテンプレートです。

## フロントエンドテスト生成プロンプト（Jest/React Testing Library）

```
以下のコンポーネントのユニットテストを作成してください。

【対象コンポーネント】
（テスト対象のコンポーネントコードを貼り付けてください）

【テスト観点】
- 正常系: コンポーネントが正しくレンダリングされること
- 正常系: ユーザーインタラクションが期待通り動作すること
- 異常系: エラー時に適切なメッセージが表示されること
- 境界値: 空データや大量データの場合の動作

【制約】
- Jest と React Testing Library を使用すること
- TypeScript で記述すること
- AAA パターン（Arrange/Act/Assert）で記述すること
```

## バックエンドテスト生成プロンプト（pytest）

```
以下のコードの pytest テストを作成してください。

【対象コード】
（テスト対象のコードを貼り付けてください）

【テスト観点】
- 正常系: 期待する入力に対して正しい出力が返ること
- 異常系: 不正な入力に対して適切な例外が発生すること
- 境界値: エッジケースの動作確認

【制約】
- pytest を使用すること
- フィクスチャを活用すること
- モックが必要な箇所は unittest.mock を使用すること
```
