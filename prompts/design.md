# 設計プロンプト

## 概要

このプロンプトは、GitHub Copilot や他の生成AIを使用してシステム設計を支援するためのテンプレートです。

## アーキテクチャ設計プロンプト

```
以下の要件に基づいてシステムアーキテクチャを設計してください。

【要件】
（docs/requirements.md の内容を貼り付けてください）

【出力形式】
- システム構成図（テキスト形式）
- 各コンポーネントの役割説明
- データフロー
- 使用する技術スタックの推奨と理由
```

## API 設計プロンプト

```
以下の機能要件に基づいて REST API を設計してください。

【機能要件】
（設計する機能の要件を記述してください）

【出力形式】
- OpenAPI 3.0 形式の YAML
- 各エンドポイントの説明
- リクエスト/レスポンスのスキーマ定義
```

## データベース設計プロンプト

```
以下のエンティティのデータベーススキーマを設計してください。

【エンティティ】
（設計するエンティティを記述してください）

【出力形式】
- ER 図（テキスト形式）
- テーブル定義（カラム名、型、制約）
- インデックス設計
```
